# Doc Alchemist

**Convert Markdown ⇆ Word ⇆ PDF with beautiful themes.**

*Made with ❤ by Hassan Ali*

| From | To |
|------|----|
| Markdown | Word (.docx), PDF |
| Word (.docx) | Markdown, PDF |
| PDF | Markdown, Word (.docx) |

Pick from three built-in document themes — **Elegant** (serif, deep
navy), **Modern** (clean sans, blue) and **Minimal** (black & white) —
and your converted files come out styled, not bare.

## Download

Grab the installer for your system from the
**[latest release](../../releases/latest)**:

| OS | File | Install |
|----|------|---------|
| Linux Mint / Ubuntu | `doc-alchemist_*_all.deb` | Double-click it, or `sudo apt install ./doc-alchemist_*_all.deb` |
| Windows 10 / 11 | `DocAlchemist-Setup-*.exe` | Run it and follow the wizard |

Both installers set up everything the app needs (pandoc, LibreOffice,
markitdown) — no manual steps.

## Usage

Open **Doc Alchemist** from your menu, drop a file on the window (or
click to browse), pick the output format and theme, hit **Convert**.
The converted file is saved next to the original — existing files are
never overwritten (a `-1`, `-2`… suffix is added instead).

## Themes

| Theme | Look |
|-------|------|
| Elegant | Georgia serif, deep navy headings |
| Modern | Calibri, vivid blue headings |
| Minimal | Arial, black & white |

Themes are generated by `make_themes.py` — tweak the `THEMES` dict
(colors, fonts, sizes) and re-run it to restyle.

## How it works

- **Markdown → DOCX** — [pandoc](https://pandoc.org) with a themed
  *reference docx* (fonts, colors and sizes baked in).
- **Markdown / DOCX → PDF** — the themed docx is exported to PDF by
  [LibreOffice](https://libreoffice.org) headless, so PDFs match the
  docx theme exactly. If LibreOffice isn't installed it falls back to
  MS Word (Windows), and as a last resort to a built-in pure-Python
  renderer (`simple_pdf.py`, basic but themed).
- **DOCX → Markdown** — pandoc (GitHub-flavored Markdown, embedded
  images extracted to a `_media` folder).
- **PDF → Markdown** — [markitdown](https://github.com/microsoft/markitdown)
  (falls back to `pdftotext` when markitdown isn't installed).

## Run from source

### Linux Mint / Ubuntu

```bash
./install.sh
```

That installs pandoc / LibreOffice / GTK bits via apt, creates a local
`venv/` with markitdown, and adds **Doc Alchemist** to your menu.
Run it from the menu (Office → Doc Alchemist), or:

```bash
python3 app.py
```

### Windows 10 / 11

1. Clone or download this repo.
2. Install [Python 3](https://python.org/downloads) if you don't have it
   (tick **"Add Python to PATH"** during setup).
3. Double-click **`install-windows.bat`** — it installs pandoc and
   LibreOffice through winget, sets up markitdown + drag-and-drop
   support, and puts a **Doc Alchemist** shortcut on the Desktop.

The Windows app is `app-windows.pyw` (Tkinter — no GTK needed).
If LibreOffice isn't installed, PDF export can also use MS Word via
`docx2pdf` (`venv\Scripts\pip install docx2pdf`).

### Command line

The conversion engine works without the UI:

```bash
python3 converter.py file.md pdf modern
```

## Project layout

- `app.py` — GTK 3 user interface (Linux)
- `app-windows.pyw` — Tkinter user interface (Windows)
- `converter.py` — shared conversion engine
- `updates.py` — update / dependency checker behind the
  "Check for updates" button (also runnable: `python3 updates.py`)
- `simple_pdf.py` — built-in fallback PDF renderer
- `make_themes.py` — generates `themes/*.docx`
- `themes/` — themed pandoc reference documents
- `install.sh` / `install-windows.bat` — per-OS setup from source
- `build_deb.sh` / `installer.iss` — Linux and Windows installer builds

## Releasing

Pushing a version tag builds the `.deb` and the Windows setup `.exe` in
GitHub Actions and publishes them as a release on this repo:

```bash
git tag v1.3.0
git push origin v1.3.0
```
