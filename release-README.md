# Doc Alchemist

**Convert Markdown ⇆ Word ⇆ PDF with beautiful themes.**

*Made with ❤ by Hassan Ali*

| From | To |
|------|----|
| Markdown | Word (.docx), PDF |
| Word (.docx) | Markdown, PDF |
| PDF | Markdown, Word (.docx) |

Pick from three built-in document themes — **Elegant** (serif, deep
navy), **Modern** (clean sans, blue) and **Minimal** (black & white) —
and your converted files come out styled, not bare.

## Download

Grab the installer for your system from the
**[latest release](../../releases/latest)**:

| OS | File | Install |
|----|------|---------|
| Linux Mint / Ubuntu | `doc-alchemist_*_all.deb` | Double-click it, or `sudo apt install ./doc-alchemist_*_all.deb` |
| Windows 10 / 11 | `DocAlchemist-Setup-*.exe` | Run it and follow the wizard |

Both installers set up everything the app needs (pandoc, LibreOffice,
markitdown) — no manual steps.

## Usage

Open **Doc Alchemist** from your menu, drop a file on the window, pick
the output format and theme, hit **Convert**. The converted file is
saved next to the original (existing files are never overwritten).

## Under the hood

Conversions are powered by [pandoc](https://pandoc.org),
[LibreOffice](https://libreoffice.org) and
[markitdown](https://github.com/microsoft/markitdown).
